# 中文书与教材的版式

把 HTML/pandoc 产物排成"像一本书"而不是"一个网页"。核心不是审美，是**参数与层级**；参数对了，观感自然对。

**当读者说“怪”而参数都量对了，先去查“附件”**：表、图、步骤、注这类附件最容易还停在网页形态（表没表号、步骤挤成一段、图不分档、注是斜体大段）。典型判词：**正文按纸书排了，附件还按网页排**——他感到的不是“丑”，是“用得别扭”：一查表找不到表号，一卡住看不见第几步。

## When to Use

- 用 `offline-html-book` 出了一本书/教材/白皮书，但读者反馈"说不上来哪里怪"。
- 需要定版心、字号、行距、缩进、三线表、图注、断页规则。
- 要出可打印的 PDF（A4 / 16 开 / 21×26 等定尺），且要求字号与设计值一致。

不适用：单页海报（`html-long-image-rendering`）、Word 交付（`pandoc-md-to-docx`）。

## 十条硬规则（都有量）

1. **先量，再改**。动手前必须从现有 PDF 量出四个数：正文实际字号(pt)、行距(pt)、每行字数、四边页边距(mm)。用 `scripts/measure_pdf.py`。**CSS 里写 10.5pt 不等于印出来是 10.5pt**。**它的「版心 / 每行字数」两项会虚高**：脚本把全页墨迹与 span 合并统计，带副区、图表、页眉时会偏大；正文宽度须用单页 span bbox（滤掉 y<20mm 的页眉）复核。**判「有没有被整页缩放」看字号直方图，不看中位数**：表格字（8.8pt）、图注（8.5pt）、题解字会把中位数拉下去，一本书表多时正文 10.5 也会被报成 8.8——按页统计 `Counter(round(span.size,2))` 并按字符数排序，正文号必须排第一。
2. **警惕整页缩放**。Chrome 打印按「适合可打印宽度」**整本等比缩小**：文档里只要有一处元素宽过可打印区（本书 180 mm），**全书**都缩（实测 0.889 与 0.84 两例：边距分毫不差、字号全小一号，单页极难发现）。四个来源，逐个堵：① 超宽行间公式——`.katex-display{max-width:100%;overflow-x:auto}`；② `main{padding-left:34mm}` 这类把副区写进 padding 的——改成 `main > *{margin-left:34mm}`；③ **`body{width:210mm; padding:22mm 15mm}` 在打印里仍生效**——210+30=240 mm，在 `@media print` 里补 `html,body{width:auto;margin:0;padding:0}`，边距只由 `@page` 给；④ **pandoc 给部分表写行内 `style="width:100%"`**——100% 按版心 180 mm 算，再叠 34 mm 左边距就是 214 mm，`max-width:100%` 拦不住（它本身就是 100%），必须 `table:not(.wide){width:146mm !important}` 并在成形阶段给列宽合计 ≥176 mm 的表补 `class="wide"`。定位用 `document.body.scrollWidth`：等于 214 mm 就是「宽元素＋副区边距」，等于 240 mm 就是 body 自带宽度；再逐个量 `getBoundingClientRect().right`，**跳过 `closest("svg")` 与 `closest("math")`**（KaTeX 伸缩字形是 `width="400em"` 的内联 SVG，量出来 5000+ px，会淹没结果）。
3. **正文 10.5pt / 行距 17pt**（1.62），**每行 38–42 字**。行长超过 45 字，眼睛回扫会丢行。教材若留左副区（`references/textbook-layout-cn.md`），主栏常压到 33–39 字——那是参照书的实况，不算违规。
4. **段距归零，界线交给缩进**：`p{margin:0;text-indent:2em}`。网页式的"空行分段"是中文书最明显的假味。
5. **标题靠字族+字号双通道**：章题黑体 24–25pt、节题 14pt、小节 11.5pt；正文用宋体。同级标题只用一种区分手段（既加粗又变色又加线＝失控）。
6. **三线表**：只有顶线、表头线、底线，无竖线、无斑马纹；**上下线要比表头线粗一档，但档位只能取 0.75pt 的整数倍**——实测 CSS 写 `1pt` 与 `0.5pt`，Chromium 按 96 dpi 取整，**落到纸上都是 0.75pt**（`border-top/bottom: 1.5pt` + `thead th{border-bottom: .75pt}` 才是真的粗细分明）。字号 8.8–9pt、行距 11.4–11.6pt——默认继承正文 17pt 行高会让表看着像网页表。表内容**一律左对齐、上下居中**（用户定的规矩）：连纯数字格也左齐，只保留 `font-variant-numeric:tabular-nums` 让数字列等宽；`th,td{vertical-align:middle}`，不要 `top`（单行行看着悬）。数字右对齐会让整表看着歪——除非用户另说。
7. **表格列宽按内容算，不按列数分档、也不交给浏览器**。六步：① 格内有 `①②③` 圈号，先在每个圈号前插 `<br>`（不定断点，量出来的宽毫无意义）；② 逐列取「最长那条不折行」的估算宽 + 内边距，**首列必须一行放完，任何情况下不压它**；③ 各列最小宽之和 ≤ 主栏就把余量均分到各列；④ 放不下就开副区（主栏 146 → 版心 180）再均分；⑤ 180 仍不够，**才**在非首列的 `；`→`，`→`、` 处找断点，且**只断该列最长的那一格**（断短格减不了列宽，白折一行），断完回②重算，直到放得下或再无点可断；⑥ 仍不够才等比压缩，首列保宽不动。算完把 **mm 值**写进 `colgroup` 并 `table-layout:fixed` 锁死。**`table.wide` 必须同时写 `width:180mm`**——只写 `margin-left:0` 不写宽，宽表仍被压回主栏宽、每列都折，症状极像「算法算错了」（实测列宽算 21mm 却按 17mm 排）。判「要不要破栏」由量算决定，不靠人手标 class。跨页仍要**行不拆、表头重复**：`tr{break-inside:avoid}` + `thead{display:table-header-group}`；整表 `break-inside:avoid` 会制造半空页。
8. **图的宽度默认跟正文列，不跟版心**。有左副区时，图默认按**主栏宽**（如 146mm）出、就放在主栏里；只有真的放不下（双栏对比、多标注、多子图）才按版心宽出（如 180mm）并 `figure.wide{margin-left:0;width:180mm}` 伸进副区。**「能宽就宽」是错的**：满版图一多，页面会显闷且副区失去意义。**图内字与图注同号**（现定 8.5pt，与 `figcaption` 相等）——出图前用 `re.sub(r"fontsize=\s*[\d.]+", "fontsize=8.5", src)` 把脚本里所有显式字号压平（rcParams 管不到硬编码值，一章常 20+ 处）；matplotlib 的上下标按 0.7× 自动缩到 5.9–7.3pt，那是数学角标的固有行为，不算破例。**图内去字要按图的种类分开，不能一刀切**：**数据图**（曲线、条形、谱线）只留坐标轴、图元与箭头，(a)(b) 小标题、图例、注记撤到正文，带字的注记箭头也一并删（字一撤，引线就成指向空气的杂线；`FancyArrowPatch` 画的流程箭头例外，保留）；**示意图**（剖面、靶片、几何、流程）的标注**必须保留**——那些字就是图的内容，删了就成哑图。用户先要求「一律去字」，随即纠正「演示性质的图不要删」，故成形时按名单分两类：数据图挂空 `Axes.text/legend/set_title/annotate`，示意图原样出。实现见 `references/textbook-layout-cn.md` 的「图内极简」。**线径与三线表同档**（见第 6 条）：坐标轴 = 表粗线 1.5pt、网格与主刻度 = 表细线 0.75pt、数据曲线 1.5pt；出 SVG 后再钳一道 `stroke-width`（>1.5 → 1.5、0.8–1.0 → 0.75），否则脚本里显式写的 `lw=2.0` 会比坐标轴还粗，用户一眼看出「最粗的不是轴」。
9. **行间公式上下留白 6–8pt**。公式多的教材，`margin:17pt` 会把整页撑散、页数暴涨。
10. **练习与算例一步一行**：题干 → 已知（逐项）→ 解 → 编号步骤（一步一公式、中间数字成行、单位在行末）→ 答。用分号串成一段是"不像教材"的头号原因。
11. **表格列宽先看 pandoc 给了什么**。pandoc 把每张表写成带 `<colgroup>` 的等分列宽（`<col style="width: 25%">`），**行内样式压过样式表**，写 `td:nth-child(n){width:…}` 或 `!important` 都是绕路。正解：成形脚本重写整份 `colgroup` 为 mm 值（见第 7 条），配 `table-layout:fixed`——浏览器不再自作主张。
12. **图在最终印刷宽度上设计，且宽度是「事后可判」的**。`figsize` 宽 = 该图实占的印刷宽度（主栏 146mm 或破栏 180mm，不是一律版心宽），再用 `像素宽 ÷ dpi`（矢量则读 SVG 的 `width` pt）复核。**破栏判定交给脚本**：成形时读 `<img src>` 对应 SVG 的宽度，>主栏宽若干才加 `.wide`——人写 class 必忘。**事后把画布缩小不叫归一化**：手摆的标注会互相压住、标题会压到图上，且 `bbox_inches="tight"` 会重算尺寸，`set_size_inches()` 不能保证输出的英寸数。
13. **旁置图只给"单幅 + 少标注"的图**。窄栏（74 mm）实际可用宽度约 64 mm：一条 9 pt 的说明超过 64 mm 就放不下，塞进去只能删内容或把字缩到 6 pt——两条都不做。多数列、多标注的细节图才破栏到版心宽。
14. **习题与详解分家**：章末「动手算一算」只列题干（题号 N-1、N-2……与书末题解一一对应），**不冠「本章 N 题，详解见书末…」这类指引句——题号本身就指了路，多说一句就是废话**。整块**彻底启用副区**：自版心左沿（而不是主栏左沿）起、宽 = 版心宽（如 180mm），题号与题干同行；折行不再追平题干首字（那是主栏内的做法，满宽块不必）。逐步详解集中到书末《题解》一章。题干一律从原稿取——改过文的版本里往往已把题目删走；成形时题干整体包一个 `<span>`（见「常见坑」里 flex 拆公式那条）。
17. **章末栏目（本章要点、本章术语）不打圆点**：要点的每一条本身就是一句完整的话，圆点只是装饰。改成**段落式**：`ul.points{list-style:none;padding-left:0}` + `li{text-indent:2em;margin:0 0 2.5pt}`——层级已由「本章要点」那条通栏色条交代，不需要再给符号。
15. **三级标题带号**（5.1.1、5.1.2……）：节号取自 h2 里的 `span.secno`，随节走、每节从 1 起；无编号的节（本章要点、题解小节）下不编号。一次遍历完成；号码与标题**同号同字重**（如 11pt），只以主色区分——小一号会看着像外挂上去的注，用户会要求「字体大小统一一下」。

16. **正文文风四条**（用户定的硬规矩，每条都可机器验收）：
    - **不许 AI 腔与“正确废话”**。“请记住”“简单来说”“一句话讲清楚”“我会稳稳接住你”“这说明了一切”这类一律删。判据很硬：删掉这句，读者少了什么？什么也不少，就是废话。
    - **正文不出现任何编号**：（1）（2）（3）不行，`①②③` 也不行。要分点就直接写成叙述，或把每条的题眼加粗——例如「四条守恒」不编号，只把**电荷数守恒**、**核子数（质量数）守恒**、**能量守恒（含静质量）**、**动量守恒**四个名字加粗。圈号只许出现在**表格**里（那里它是列宽算法的断行锚点，不能删）。**章首「本章要解决的问题」下的 1./2./3. 属导读清单，不算正文分点**（样张如此，勿当违规删掉）。
    - **加粗是重点信号，不是语气**。每千字 < 4 处（约一章 30 处内）；公式、数据、结论里只标真正要背的那一句。版式标记（`**旁注**`、`**本章要解决的问题**`、`**这张图要读出什么**`）不算在内，且绝不可动。
    - **专有名词首现要标**：`<span class="term">截面</span>（<span class="en">cross section</span>）`——中文主题蓝黑体、括号内英文真斜体（`DejaVu Serif` italic，不要合成斜体）；同一词全章只标一次；不标在标题、旁注、表格、图注里。英文名取本章「本章术语」表里的那个，不自编。

    改文风时**数字与公式一个都不许动**：交稿后抽数字串做集合比对（`set(v6 数字) == set(v7 数字)`，相等即未丢未改），汉字数只许少几十（删废话的量）。交稿前跑 `scripts/style_lint_cn.py <章.md>`：AI 腔 0、括号编号 0、**正文圈号 0**（表格里的不算）、加粗 < 4/千字、term ≥ 8。改后由主上下文复核——子代理的自评会漏掉“表崩了”这类版式事故，文风项同样要用脚本的实际输出说话。

## 工作流

```bash
# 1. 量现状
python3 scripts/measure_pdf.py 书.pdf            # 字号/行距/页边距/每行字数
# 2. 定版心（A4: 版心 148×234，天头 28 地脚 35 订口 32 切口 30）
# 3. 套 CSS（references/html-book-css.md 有整段可粘）
# 4. 重建 → 再量一次，字号必须回到 10.4–10.6pt
# 5. 抽页看：封面/目录/章首页/公式页/表页/图页/练习页/附录
```

### 换开本 / 换风格：先做一章样张，不动全书

1. **挑一章图、表、公式、习题俱全的典型章**，建 `版式对照_<风格>/` 目录：`build.sh`（备料→pandoc→chromium）+ `工具/shape.py`（章首页/节号牌/栏目条/边注等成形）+ `工具/finish.py`（页眉页码书签）+ `工具/对照图.py`（新旧并置）。
2. **新旧并置出图**，两版按同一 px/mm 缩放、标上「旧 A4 210×297 / 新 …」。用户凭这个判合身与否，只给 PDF 他不会翻。
3. **几何参数只存一处**：版心宽、`--side`（副区）、`@page` 边距各有一个数，其余全由它算。改开本只动 `@page size` + 边距 + `finish.py` 的 `PAGE_W`；改副区才动 `--side` 与让位值。散落成字面量必出「标题缩进了、正文没缩进」。
4. **改完三重复测**：字号中位数回到 10.4–10.6（防整页缩放）；左白 = 右白；副区左沿 = 版心左沿 = 页眉线起端（用 `scripts/page_guides.py` 出图核）。
5. 定版后才推全书：图重出、题重排、目录封面索引重走，并先算出页数代价。逐章可并行两路——一路重写正文（拆段、旁注压到 ≤60 字、图内细则移入图注）、一路写三列式题解；两路都只准写 md，构建与版式留在主上下文。子代理回来必须自己复核：数字抽比、旁注逐条数汉字、`shape.py` 的计数行（章首页/节题/边注/破栏图）对不对得上——它们的自评会漏掉“表崩了”这类版式事故。

## 前置页：封面、版权页与目录（成书必备）

正文排得再好，少了前置页也不是书。定稿页序：**封面 → 封二空白 → 版权页 → 版权背空白 → 目录 → 正文（卷首／章）**。用户把这两页空白都叫「封面背面」，两处都要加，别问是哪一页。

- **封面**：白底；顶部一条通栏 180 mm 的重复纹样带（高约 58 mm，用**本学科的意象**当单元，不是装饰——化学用苯环阵列，核物理用「核子＋两条交叉轨道」）；书名无衬线特粗 33 pt、两行以内；书名下一行英文副题（衬线斜体 10 pt 灰）；再下一行**红色版次小标**（如「第三版 v3」，底 #b23a34、白字）；书名上方一行小字标系列。**所有文字右对齐**：订口在左，视觉重心放切口侧；纹样图不受 `text-align` 影响，仍通栏。
- **版权页**：半页够。书名（22 pt 粗）、副题（11 pt 灰）、一道 40 mm 主色细线，下面三行 9.5 pt 居中（卷次与内容范围、版次与月份、开本与正文磅值与印色）。自印本的说明放**离底边约 60 mm、居中、不用句号、一句一行**（`position:absolute;bottom:60mm`）。
- **目录**：跨满版心 180 mm，但**分两区排**——章号占副区（**右对齐**，框的右沿贴副区右沿），条目只在主区；**每章自成一块**（不是整页连续双栏，否则下一章的章条会吊在上一章栏尾）。章条 = 蓝底方框包「第 N 章」（白字，落在副区里右对齐）+ 黑体章名（自**主区左沿**起，与章号同一行）+ 一条拉到右端的主色下划线 + 「/ 页码」。条目区 `margin-left:34mm; width:146mm; column-count:2; column-fill:balance`——**每章条目左右各半、读序先左后右**；三层字体：章条黑体、`N.M` 宋体、`N.M.K` 仿宋并缩进约 4.5 mm；节条目点线引右端页码；章条与它下面的第一条不许断页（`break-after:avoid`）。
- **页眉归属**：封面、版权页、空白页**不排**页眉页码；目录页**排**，标签固定「目录」；正文从第一章起照常。判断用「第一章页码」（从书签取），不要只判 `p == 0`。
- **页码是第二遍的事**：目录在正文之前，页码要等正文排完才知道。流程固定为「首装（页码写 —）→ 从 PDF 书签取各级标题页码 → 回填目录 → 重装」。**页码一律取自书签，不在正文里搜标题文字**：章首页的字常加字距，「第 16 章」在 PDF 里是「第 1 6 章」；附录标题还会同时出现在目录页上。
- **定页时先跳过目录页**：目录把每个标题都印了一遍，按文字定页的脚本若不过滤，全部书签都指到目录上，目录页码与索引页码一起崩。
- **任何改分页的改动都会让目录与索引失效**：加前置页、补图、修正文之后，目录页码与术语索引页码都要重算；顺序是「目录 → 索引 → 终装 → 复核」，且索引要连跑两遍页码不变。

一层章的简目只适合小册子；教材用三层（章／节／小节），层次本身就是知识结构。具体 HTML/CSS 与脚本（`make_front.py`／`toc_pages.py`）的实现，见 `hep-textbook-rebuild` 技能里那份 front-matter-and-toc 参考文件。

## 常见坑

- **`@page:first{margin:0}` 必须写在最后**，否则被普通页规则覆盖，封面缩进版心。
- **章题降位用 `::before` 撑高，不要用 `margin-top`**：分页处外边距会被折叠，章题贴天头。
- **`h1{break-before:page}` 会让每章另起**，目录/附录也各占一页；想省页就在附录上关掉。
- **`orphans/widows` 只对段落生效**，标题要用 `break-after:avoid`。
- **表题要落在 `table` 块里才会变成 `<caption>`**。若为了加列宽 class 把表包进 `<div class="tablewrap">`，表题那一行必须一起搬进去；留在 div 外的表题会退化成普通段落（症状：表有名字但目录/书签里认不出，样式也不生效）。**同理，用 pandoc 的 `: 表 N-K` 写法时，该行必须紧贴表格（表格的下一行）；写在表前又隔了空行，pandoc 不当 caption，PDF 里就是一条 10.48 pt 的正文段落、左对齐——表题数会和表数对不上，但字面上看不出来。****表题与图注同款**：宋体 8.5pt、居中、`caption-side:top`（位置在表上，样式随图注）；CSS 只写 `width:146mm; text-align:center; padding:0`，宽表用 `width:180mm`——给 `caption` 加左右 padding 会把整张表一起推右（caption 盒宽参与表盒计算，实测右移 14mm），`margin:auto` 对表题盒也不生效。量法：PDF 里表题中心应等于表中心（版心 15+34+146/2 = 122mm）。
- **`$$…$$` 不能放进 `<li>`**。pandoc 在 HTML 块里不解析它，KaTeX 会拿到裸 `$$` 报错。步骤里的公式改成行内 `$…$`，或关掉列表、单独一段行间公式再续列表。
- **目录分栏用 `balance`，不用 `auto`**：`column-fill:auto` 会先把左列堆到底，内容短的章全堆左列，只有条目多的章（如附录）溢出到右列——成品就是「为什么只有那一章分成两半」。教材目录要的是每章条目左右各半、读序先左后右 → `column-fill:balance`；核对办法是抽一章数左右列条目（应相近），不是看总页数。
- **行首禁则在 Chromium 里做不到，别再试**：`line-break:strict` 不生效；插 U+2060（WORD JOINER）反而更糟（Chrome 允许在它**之前**断行，实测 71→72 行）；把「前一字＋标点」包成 `white-space:nowrap` 也无效（Chrome 允许在行内盒**边界**断行）。三种都已量过，验收单里如实写「已知缺陷」。
- **pandoc 的 HTML 块会后接的 ATX 标题当正文**：`<span id="x"></span>` 紧跟 `# 题解` 而中间无空行时，PDF 里会印出字面的「# 题解」。任何手写 HTML 块与标题之间必须空一行。
- **图注居中与否看参照书，别想当然**。教材样书是**居中**的（8.5pt、`max-width:118mm; margin:auto`）；超过两行居中会参差，故先居中、再看三行以上的图注是否显散，散则只对该类改左对齐。图号用主色加粗、后接全角空格，与正文同字族（宋体），不要黑体。**图注只写一句**（≤35 字、一行放下）：细则、阈值、读数一律搬到图后那段正文（「这张图要读出什么」），图注不是小作文；图内注记挪三次仍压线或溢框的，直接删——正文讲过就不必在图里重复。
- **改后处理时，引文块只能逐块扫，不能用跨块正则**。`<blockquote>\s*<p><strong>(.*?)</p>\s*</blockquote>` 这种惰性匹配，一旦块内还套着 `<ol>`，就会一路吞到下一个 `</p></blockquote>`，把后面几段、旁注乃至整张表都裹进浮动的 `<aside>`——症状是「表挤成一字一列、正文压在表上」。可靠做法：先按 `<blockquote>…</blockquote>` 配对切块（`find` 找到起止，不递归），块内再判是问题清单还是旁注；保留下来的内层 HTML 原样不动。
- **pandoc 的 `<colgroup>` 写的是行内 width**：`<col style="width: 33%">`，样式表压不住行内样式。**修法不是加 `!important`**（那只能救一两张表、仍是固定比例），而是在成形阶段**重写整份 `<colgroup>` 为 mm 值**并 `table-layout:fixed`——列宽由「每列最长条」算出来（见第 7 条与 `references/textbook-layout-cn.md`）。
- **封面/扉页的大片空白必须「有交代」**：标题块压上三分之一、版权信息压底，中间那片不写东西就会像「没画完」。给中间一个安静元素（一句题记、一行副题、一条细线），并把它落在 60–70% 高度——空白就从「没画完」变成呼吸。题记类段落要 `text-indent:0`，且必须在**打印块里**也定义一次（屏幕样式里的规则在模板被重写后容易掉）。
- **行内公式不能坐在 flex 容器的散文中**：`display:flex` 会把段落里的文字、`<strong>`、KaTeX 的 `<span>` 各拆成一个匿名 flex 项，公式与文字被甩开（症状：「Q = … MeV」中间空一大片）。要做「题号＋题干」两段式，就把题干整体包进一个 `<span>`，只留两个项参与 flex。
- **页眉要先向天头“借”空间**：页眉基线距纸顶 h mm 时，天头至少 h+7（页眉字高约 4、细线再下 2.6、与版心留约 4）。用户说「页眉距顶端 15mm」时，天头必须放到 22mm、版心高随之少 7mm；若坚持四边齐 15，页眉只能压到 8.5mm 基线（已贴纸边）且与首行正文抢那根线。改页眉位置要同时改 `@page` 上边距与 `finish.py` 的 `M_TOP`/`y_txt`，漏一边就是页眉压字或版心空顶。
- **小图的字压字要机器判，不靠目测**：60 mm 上下的小图，手调 `subplots_adjust` 常把横轴标签挤出画布，`savefig` 不报错、直接裁掉 → 用 `layout="constrained"`，图幅不变、坐标区自动让位。交稿前做一次 bbox 自检：只取轴标/标题/`ax.texts`/图例/落在 `get_xlim()/get_ylim()` 范围内的刻度，两两 `bbox.overlaps()`，交叠面积 >2 pt² 即报；审全图 `findobj(Text)` 会把范围外的刻度也算进来（matplotlib 给它们也建了 Text 对象，但根本不画），全是假阳性。
- **中文字体只用本机已装的**（离线要求）：`Noto Serif CJK SC`（正文）/`Noto Sans SC`（标题）。
