# 图表规格 v3（2026-10-26 定）

适用于《从零开始的核物理与核能》全书插图与表格。旧的 `hep-textbook-rebuild` 技能里「数据图默认 146mm、宽图 180mm」的规矩**作废**，以本册为准。

## 一、图的尺寸（硬指标）

| 项目 | 值 |
|---|---|
| **最大宽度** | **65 mm**（主栏 146 mm 的 45%，向上取整到 65） |
| 常用宽度 | 单曲线 52 mm／双曲线 58 mm／带图例 65 mm |
| **最大高度** | **78 mm**（含轴标；超过即压缩纵横比或拆图） |
| 图内字号 | **一律 8.5 pt**（轴标、刻度数字、图例、示意标注，全部同号） |
| 图注字号 | 8.5 pt，居中，一行 |
| 线宽 | 坐标轴与曲线 **0.75 pt**；网格与主刻度 **0.4 pt**；次刻度不画 |
| 画布 | 按印刷宽度出图（`figsize=(65/25.4, h/25.4)`），插入时**不缩放** |

判据只有一条：**图内 8.5 pt 就是纸上 8.5 pt，任何图都不许靠 CSS 缩放来「塞进版面」。**

## 二、图的分类与文字

### 数据图（折线统计图为主）

图内只留坐标轴、轴标（含单位）、刻度数字和必要的短图例（每条 ≤4 字）。解释句、公式、阈值说明，以及「峰值」「门槛」「注意」这类注记、色块里的文字、(a)(b) 分栏标号，都不进图。
曲线多于三条时，改线型（实线/虚线/点划线）区分，并在图注里一句话说明，不在图内堆图例。

### 示意图（演示图）

标注是图的一部分，要保留，但有下面三条限制：

- 每个标注 ≤5 字；全图标注总字数 ≤24 字；
- 标注不得压线、压箭头、压剖面边界；
- 尺寸、角度这类数字只留必要的（如「15.5 MPa」「377 ℃」），其余移入图注或正文。

### 双拼、三拼图

拆成独立单幅图，各自编号（图 5-2、图 5-3），各自配一行图注。理由：65 mm 宽下每格只有 32 mm，8.5 pt 字会互相压住。

## 三、图注

- 一行，格式：`图 N-K　短题`，短题 ≤20 字，句末不加句号；
- 细则（「这张图要读出什么」）放进正文，一段 2–3 句，紧跟图后；
- 一个图一条注，不写「左：…；右：…」，因为不再有左右。

## 四、表格

| 项目 | 值 |
|---|---|
| 默认宽度 | 主栏 146 mm；五列以上或首列 >40 mm 时才破栏到 180 mm |
| 线 | 上下框 1.5 pt、表头下 0.75 pt，中间无线 |
| 字号 | 正文 9.5 pt；表内数字 9.5 pt，纯数字列右对齐 |
| 表题 | 表上方，`表 N-K　短题`；**与图注同款**——衬线 8.5 pt、居中、宽 ≤118 mm，表号着主色 |
| 单元格 | 首列必须一行；圈号 ①②③ 各自起行；禁 (1)(2)(3) |

## 五、出图流程（工程）

1. `code/fig_chNN.py` 是原稿，**不改**；新脚本写在 `code/fig_chNN_v3.py`。
2. 新脚本只用 matplotlib，`svg.fonttype='none'`，`figsize` 按上表毫米数换算英寸。
3. 每张图一个 `save_v3(fig, "chNN_figK")`，输出 SVG 到 `图v3/chNN/`。
4. 出图后跑 `工具/figcheck.py`：读 SVG 的 `width/height`（pt→mm）与全部 `<text>` 的 `font-size`，任何一张超 65×78 mm 或字号 ≠8.5 pt 即报错。
5. 装配时用 `figure img{width:auto}`；`max-width:100%` 会把图缩小，不要用。

## 六、数量

每章 3–5 张（拆图后按单幅计）。全书预计 90–120 幅。每张图都要在正文里有引用（「如图 N-K」），没有引用的删掉。

## 七、配色

主色 `#2f6f9f`；辅助黑 `#1a1a1a`、灰 `#6b6b6b`、浅灰 `#c9d2da`；底纹 `#eef3f7`。
双色印刷可分辨即可，不引入第三色相。
