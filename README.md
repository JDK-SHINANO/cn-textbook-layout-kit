# 信浓教材版式套件 · 中文教材排版工具链

一套让 AI 生成「像教材的中文书」的版式与写作规矩：**Hermes 技能 + Python 工具 + HTML/CSS 模板 + 可编译样张**。

样式参照北京大学出版社《基础有机化学》（第 4 版）——只借它的骨相（开本、左副区、章首色砖、页眉、三线表），未复制其中任何内容。

**先看效果**：`05-样张/样张-第5章.pdf`（21 页，成品）与 `05-样张/校_*.png`（抽页）。

> 完整参数、依赖、目录约定、雷区清单都在 [`README.md`](README.md)。这里只列要点。

## 一图看懂

| 项目 | 参数 |
|---|---|
| 开本 | 210×260 mm（天头 22／地脚 15／左右 15） |
| 版心 | 180×223 mm ＝ **左副区 34 ＋ 主栏 146** |
| 正文 | 10.5 pt／17.2 pt，39 字 × 36 行 |
| 页眉 | 基线距纸顶 15 mm，细线 17.6 mm，页码贴切口 |
| 三线表 | 上下 1.5 pt、表头线 0.75 pt |
| 图 | 线宽两级（1.5／0.75 pt），图内字 8.5 pt＝图注字号，**SVG 矢量字** |
| 双色 | 黑 ＋ 墨蓝 `#2f6f9f` |

## 仓库结构

```
01-技能-hep-textbook-rebuild/   整书重排流程册（九个雷区、子代理简报模板）
02-技能-book-typography-cn/     中文书排版通用知识 + 量尺脚本
03-工具/                        shape / finish / figs / 文风检查 等
04-模板/                        template.html + build.sh
05-样张/                        第 5 章 md、题解、成品 PDF、抽页 PNG
06-参考/                        bookstyle.py、对照报告
```

## 三件最有用的东西

1. **表格定宽算法**（`03-工具/shape.py: fit_tables()`）：按内容量宽、首列不许折行、放不下才开副区、再不够才在 `；` 处断——附「量宽前必须剥 LaTeX」的教训。
2. **图的两种规矩**：数据图去字、示意图留字；SVG 出图、画布按印刷宽度校准，插入不缩放，图内字号即纸上字号。
3. **文风检查器**（`02-技能-book-typography-cn/scripts/style_lint_cn.py`）：把「AI 腔、括号编号、加粗滥用、术语首现未标」变成可数的指标。

## 已知缺陷（不是没做）

- 行首标点：Chromium 打印不实现 `line-break:strict`，约一成行以标点起行（U+2060 与 nowrap 片段均无效）。
- 宽图推页会留白；跨页表未标「续表」。
