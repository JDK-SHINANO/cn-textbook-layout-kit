# 子代理简报模板（实测可用）

派多路并行，每路一份自包含简报——子代理看不见主对话，路径、格式、硬约束、禁改项都要写进去。简报宁可长，不可省；省一句，它就自己发明一句。

## A 路：正文改写（v3）

附上：章号、输入 md 路径、输出路径、`写作须知_v4`、`references/spec-v3.md`、本章的缺口诊断与病灶清单（带行号）。要求：

1. 骨架照 ch05_v8 排：章首 `> **本章要解决的问题**` + 1./2./3. 疑问清单；`## N.M` + `###` 三级标题（`它要解决什么问题` 型全章 ≤3）；算例以 `**算例一：…**` 起头；章末 动手算一算（只留指引）→ 本章要点 → 本章术语表 → 收束段 → （本章数值出处）→ 口径说明。**不设例题编号、公式编号、参考文献小节。**
2. 其余导语式小标题（「麻烦来了」「为什么会这样」）改成实义名词短语；`它要解决什么问题` 只留 ≤3 处。
3. 文风 v3：AI 腔 0、意象 0、口号 0、加粗 ≤4/千字、「你」≤2/千字、term ≥8。
4. 补知识按诊断单逐条落位，每条补在「读者会卡住」的那一节，不许增设与主线无关的章节。
5. 旁注 `> **旁注**\u3000…` ≤60 汉字，每节 0–2 条。
6. **不许改**：物理数字、公式本体、单位、有效位数、图所依据的数据。诊断单里标「待核」的数一个也不许动；只有明确判为错值的才改，且必须在交付说明里写「旧值→新值→复算依据」。
7. 三条国标规矩一次写进简报（别指望事后 steer）：禁用 ppm/ppb（改 10⁻⁶）；核素禁 `U-238`、`238U`（改 `$^{238}\mathrm{U}$` 或「铀-238」，首现 ²³⁸U（铀-238））；数值范围用「～」。
8. 另交一份 `规范/图清单_chNN.md`：每图一行——新图号｜内容一句话｜宽 mm（≤65）｜数据图／示意图｜是否由旧图拆分｜图内标注清单。
9. 自检四器全绿再交：`文风检查.py`（八项硬门槛）、`验收章.py`（不带 `--orig` 作门槛）、`规范检查.py`（U1–U11 清零，U10 允许 ≤3）、`term对齐.py`（待补 0）。数字集合与原文的差集必须能逐条解释（删题造成的缺失要列出题号）。

## B 路：题解改写

附上：原章路径（题目在「## 习题」或旧稿「## 动手算一算」里）、**该章已定稿的 vN 正文**（口径以它为准）、输出路径、`src/tijie_chNN.md`（结构样例，如 ch05）。

硬要求：

1. HTML 结构照抄：`.work / .tag / .q / .given / .steps / .step / .eq / .lead / .say / .a`。
2. `.eq` 只放公式（KaTeX），定宽列、居中；公式太长就拆成两步；实测宽度不超过 90 mm。
3. `.say` 是「这一步在做什么」，**6–14 字**，各行起点对齐。
4. 承接上一步的推导用 `.step ind`。
5. 每题 3–8 步；必须有 问题／已知／解／答 四段。
6. `题 N-M` 编号从 N-1 起（N 为章号）。
7. **物理数字、单位、有效位数与原解逐字一致**；只重组呈现，不重算。但单位、术语、核素写法、范围符要随新正文（正文把 ppm 改成 10⁻⁶、U-238 改成 ²³⁸U，题解不同步就会同一道题两种说法）。
8. 自检：KaTeX 每个行内式能解析、`.eq` 实测无溢出、数字令牌与原解差集为空；**题数＝原章「动手算一算」的题数**、题号 `N-1…` 连续无跳号、`$` 成对、ppm 0。改完把「题数/步数/最宽 .eq」三行数字写进回话，主代理看这三行就能复核，不必重读全文。

## C 路：插图重画（v3）

附上：本章图清单、原 `code/fig_chNN.py`（只读）、输出目录 `图v3/chNN/`。

1. 新脚本写 `code/fig_chNN_v3.py`，不改原脚本。
2. 每张图 `figsize=(宽/25.4, 高/25.4)`；宽 ≤65、高 ≤78；`svg.fonttype='none'`。
3. 图内全部文字 8.5 pt；轴与曲线 0.75 pt、网格 0.4 pt；主刻度 ≤5 个。
4. 数据图删掉图内解释句、公式、阈值注记、色块文字；示意图每条标注 ≤5 字、全图 ≤24 字。
5. 旧双拼图按清单拆成独立单幅，各自编号。
6. 自检：`工具/figcheck.py 图v3/chNN` 必须 0 不合格；再逐张看「8.5 pt 下是否互压」。

## D 路：按审阅报告修订（收尾轮）

附上：你负责那一卷的审读报告（`规范/审读_v3_*.md`，只给这一份）、涉及的 v8 文件路径、三器自检命令。

硬要求：

1. **A 级全改，B 级尽量，C 级择要**；不许趁机改写文风或结构。
2. 每改一条先复算：质量、能量、比值、数量级都用 Python 跑一遍，**没依据的不改**；审阅报告也可能错（见 SKILL.md 雷区 Q），子代理拒不照改时先算再判。
3. 每处数字变动写进 `规范/修订记录_*.md`：`文件:行号｜旧值→新值｜依据（算式或原文比对）`。没写记录的一律当没改。
4. 只改本卷文件；跨卷口径（同一物理量在两个卷里各写一个值、符号下标不统一）留给主编，不要自己伸手。
5. 引用了未出版章节号的，改成不带编号的说法，不得留死引用。
6. 收尾必跑三器（文风检查／验收章／规范检查）+ `term对齐.py`，全零再交。
7. 回话 ≤14 行：A 改了几条、B 改了几条、**未改的 A 与理由**、自检结果。

## 收到之后，自己跑这几条

```bash
cd BOOK/版式对照_有机化学风
/usr/bin/python3 工具/验收章.py ../src/chNN_v8.md                          # 骨架（不带 --orig，退出码才可信）
/usr/bin/python3 工具/验收章.py ../src/chNN_v8.md --orig ../src/chNN.md   # 另跑一次，只为读数字差集
/usr/bin/python3 工具/文风检查.py ../src/chNN_v8.md                       # 硬门槛八项
/usr/bin/python3 工具/规范检查.py ../src/chNN_v8.md                       # 国标可机判项
/usr/bin/python3 工具/term对齐.py ../src/chNN_v8.md                       # 术语表↔首现（待补 0）
/usr/bin/python3 工具/figcheck.py 图v3/chNN                               # 图规验收
```

数字集合的差集要能逐条解释；解释不了就是子代理改了物理，退回重做。
