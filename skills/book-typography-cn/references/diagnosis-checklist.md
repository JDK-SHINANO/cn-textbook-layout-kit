# 逐页诊断表（模板 + 一个真实案例）

## 怎么用

抽 12–15 页（封面、目录、章首页、正文、公式密集页、宽表页、图页、练习页、附录），每页填四栏：

| 页码 | 症状（必须带数字） | 违背哪条原则 | 建议改法（数值） |
|---|---|---|---|
| | | | |

原则见 `design-principles.md`，数值见 SKILL.md 的十条硬规则。

---

## 真实案例：《从零开始的核物理与核能》（A4，374 页）

诊断前实测：字号 **9.34 pt**（设计值 10.5）、行距 **16.01 pt**、每行 **43 字**、页边距 24/24/33/29 mm。
边距分毫不差，字号却小了一号。这不是设计失误，是**整页被等比缩到 88.9%** 的结果。

| 症状 | 违背 | 改法 |
|---|---|---|
| 全书字号 9.34 而非 10.5 pt；边距却准确 | 缩放事故（超宽行间公式触发） | `.katex-display{max-width:100%;overflow-x:auto}` + `td .katex{white-space:normal}` |
| 行距 1.72、段距 1.9 pt（层级反了） | 行间被推开、段间被粘死 | 行距 17pt、段距 0、首行缩进 2em |
| 章题 1.91×、节题 1.24×、小节 1.05×，且与正文同为宋体 | 三级题等于"加粗的正文" | 标题改黑体，25/14/11.5 pt |
| 12 页填充率 <50%，最低 7% | 整表/整图跳页 | 表跨页 + 行不拆 + 表头重复 |
| 练习 6 步挤成一段，单段 13–15 行 | 结构化内容没有结构 | 一步一行，见"练习题排布" |
| 表格 ①②③④ 连排，13 字/行、9 行高 | 单元格内无断点 | 格内允许换行 + 圈码后插 `<wbr>` |
| 图内 10 pt 缩成 6.2–6.8 pt | 图按 10.4 in 画、印到 6.7 in | 画布 ≤6.5 in、图内字 ≥8.5 pt |

改完复测：字号 10.46 pt、行距 17 pt、354 页（其中表格策略贡献 −30 页）。

---

## 三条判据（快速自查）

1. **字号对不对**：量正文 span 的中位 size，与 CSS 声明差 >3% 就是缩放事故。
2. **呼吸对不对**：行距/字号应在 1.55–1.7；段距应≈0 且每段有 2 字缩进。两者同时"松"或同时"紧"，层级就错了。
3. **断页对不对**：填充率 <50% 的页超过 5%，一定是整块内容在跳页。
