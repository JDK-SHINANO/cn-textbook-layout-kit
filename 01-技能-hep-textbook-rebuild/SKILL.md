# 核物理课本 v2：整书重排与文风修订

把《从零开始的核物理与核能》从 A4 网页味的一套，改造成「16 开教材」的样子，并把内容按教科书文风重写。第 5 章已做过全流程样张，其余章节照抄这套。

**做这一件事之前，先读 `book-typography-cn`**（尤其它里面的 `references/textbook-layout-cn.md`）。本册只记「这本书怎么排」与「踩过的雷」，不重复通用版式理论。

## When to Use

- 要给这本书出新版（开本、版心、图、表、题解、文风一起动）。
- 要给别的中文教材套同一套版式与流程（参数改表即可）。

## 一、定版参数（PDF 实测，勿凭记忆改）

| 项目 | 值 |
|---|---|
| 开本 | **210×260 mm** |
| 页边距 | **天头 22 / 地脚 15 / 左右各 15**（页眉需占天头） |
| 版心 | **180×223 mm** |
| 版心内分 | **左副区 34 + 主栏 146** |
| 正文 | 五号 10.5 pt / 行距 17.2 pt → **39 字 × 36 行** |
| 页眉 | 基线距纸顶 **15**，细线 **17.6**；页码贴切口，中夹竖线，偶页章名、奇页节名；章首页不排 |
| 主色 | `#2f6f9f`（与插图同色）／色砖 `#1e4a6b` |
| 三线表 | 上下 **1.5 pt**、表头线 **0.75 pt**（Chromium 只认 0.75 的整数倍） |

  src/tijie.md, tijie_chNN.md
  工具/shape.py           塑形：章首、节题牌、三级号、边注、题干、表宽、图宽、解列
  工具/finish.py          页眉、页码、书签（PyMuPDF）

**解释器**：`shape/build` 用系统 `/usr/bin/python3`（有 matplotlib）；`finish/pages` 用 `~/.hermes/Claw_Shinano/tool/marker-pdf-env/bin/python`（有 PyMuPDF）。两个不能混。

## 三、每章流程（照做，勿发挥）

1. **两路子代理并行**（简报模板见 `references/agent-briefs.md`）：
   - A 路：正文改写（段落节奏 2–5 行、旁注 ≤60 字、图注改短、习题摘出留题干）。
   - B 路：题解改写（问题／已知／解（公式｜虚线｜解析）／答，数字一字不改）。
2. **自己验**（不采信自述）：公式数、旁注数、图引用数、表格行数、标题数、数字集合差集；`文风检查.py` 四行指标。
3. **装配**：`./build.sh chNN chNN_vN.md tijie_chNN.md`；看图用 `工具/figs.py chNN`（先跑图）。
4. **抽六页审**：章首、正文带边注页、宽图页、窄图页、表页、题解首页。用 `vision_analyze` 逐页问：压字？溢出？缩进？行距？
5. **量**：`measure_pdf.py` 字号必须 10.4–10.6、行距 16.8–17.4；不对就是整页被缩放（见雷区 A）。
6. 记入 `BOOK/版式对照_有机化学风/对照报告.md`。

## 四、文风四条（已写入 BOOK/写作须知.md 第十一条）

1. 不要 AI 腔与正确废话（「请记住」「简单来说」「一句话讲清楚」）。判据：删掉这句，读者少了什么？
2. **正文不出现 1、2、3 与 ①②③（1）（2）（3）** —— 要分点就把名目加粗，多余。表格内的圈号除外。
3. 加粗是重点信号：每千字 **≤4 处**。
4. 专有名词首现：`<span class="term">截面</span>（<span class="en">cross section</span>）`；同词只标一次，不落标题／旁注／表／图注；英文取术语表那个。

自检：`/usr/bin/python3 工具/文风检查.py ../src/chNN_vN.md`，四项指标全绿才算完。

## 五、表格定宽算法（`shape.py: fit_tables()`）

1. 格内 `①②③` 先各自起行（不定断点，量宽无意义）；
2. 每列取「最长那条不折行」的宽，**首列必须一行，永不压缩**；
3. 余量均分到各列；
4. 主栏 146 放不下 → 开副区 180（`table.wide`）；
5. 仍放不下 → 在非首列的 `；`→`，`→`、` 处断行，**只断该列最长那一格**，断完重算；
6. 仍不够 → 首列不压、其余等比例收。

**量宽前必须剥掉 LaTeX**（`\mathrm`、花括号、`^_`），否则 `^{56}\mathrm{Fe}(n,n')^{56}\mathrm{Fe}^*` 被当三十多个字，列宽虚胖一倍，表格白白开副区。

已实测：表 5-1 27/21/37/61=146（主栏）；术语表 23/45/112=180（只此一张开副区）。

## 六、图：两类两种规矩

- **数据图**（曲线、谱线、条形）：图内不留解释字，只留坐标轴与曲线。
- **示意图**（剖面、几何、流程）：标注就是图的一部分，**全部保留**，删了成哑图。
- 实现：`figs.py` 把同一份脚本跑两遍（keep／strip），`FIG_SCHEMATIC=` 点名示意图；`FIG_WIDE=` 点名要 180mm 的宽图，其余按主栏 146mm 出。
- 画布 = 印刷宽度（两遍校准），插入不缩放 → 图内 8.5 pt 就是纸上 8.5 pt；`svg.fonttype="none"` 保留 `<text>`。
- 出图后钳线宽：>1.5→1.5、0.8–1.0→0.75，全图只留两级。
- 图注一句话（≤30 字），细则进正文「这张图要读出什么」；一个图一条注，不写 (a)(b) 分栏说明。

## 七、题解与题干

- 书末《题解》是**一章**，章首同款色砖（`SOLUTIONS / 解 / 书末`）。
- 每题：`问题 / 已知 / 解 / 答`；解的每一步一行，`--sayw` 由该题最长一条注解决定（右顶版心，其余左对齐），公式在余下区域居中。
- 章末「动手算一算」只列题干，**彻底占满 180mm**（自版心左沿起）；题号与题解章一致（题 5-1…）。

## 八、雷区（都踩过，别重踩）

**A. 整页缩到 83%**：`main{padding-left:34mm}` 在打印里被算成额外宽度。→ 用 `main > *{margin-left:34mm}`，且该规则必须排在 `p{margin:0}` 之后（`*` 不计权重）。症状：字号 8.7 而不是 10.5。

**B. 某一段单独蹿进副区**：给该类段落写了 `margin` 简写（`.qstem{margin:0 0 4pt}`），权重压过 `main > *`。→ 只写 `margin-bottom`。

**C. 表格塌成一字一列、正文压表**：改旁注的正则 `<blockquote>…(.*?)</p></blockquote>` 遇上块内有 `<ol>` 就一路吞掉后面几段。→ 逐块扫描（`shape.py: shape_quotes()`）。

**D. 列宽改不动**：pandoc 给每个 `<col>` 写行内 `width:33%`，样式表压不住。→ `!important`，或干脆删 colgroup 自己写 mm。

**E. 开了副区仍按 146 排**：只写了 `main > table.wide{margin-left:0}`，漏了 `table.wide{width:180mm}`。

**F. 线宽全是 0.75 pt**：CSS 写 1pt 与 0.5pt，Chromium 按 96 dpi 取整都落到 1px=0.75pt。→ 用 1.5／0.75。

**G. 行内公式被拆散**：给带公式的段落上 `display:flex`，行内子元素各自成 flex 项。→ 题干文字包进一个 `<span>`。

**H. 行首标点（70 余处）**：Chromium 不实现 `line-break:strict`；插 U+2060 反而更多（可在其前断行），包 nowrap 片段也无效（可在行内盒边界断行）。→ 如实列为已知缺陷，别假装解决。

**I. 宽图推页留白**：图放不下就整页下移，页尾空三成。排版后期人工挪图或改图幅，CSS 无解。
