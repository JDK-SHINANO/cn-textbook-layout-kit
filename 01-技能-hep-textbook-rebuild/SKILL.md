# 核物理课本 v3：整书重排与文风修订

把《从零开始的核物理与核能》从 A4 网页味的一套，改造成「16 开教材」的样子，并把内容按教材体重写（第三轮起：先文后图、图缩到 65 mm、去 AI 腔与意象、按国家教材规范补附录）。第 5 章做过全流程样张，其余章节照抄这套。

**开工前的三份底稿**：本章的定版参数与雷区、`references/spec-v3.md`（骨架／文风／图规／附录全文）、`references/agent-briefs.md`（三路子代理简报）；全书装配、整本缩放诊断与索引页码另见 `references/assembly-and-scale.md`；封面与目录的样书骨相见 `references/front-matter-and-toc.md`。

**样子＝`BOOK/src/ch05_v8.md`**（已排成 21 页 PDF 那一版；v8＝v7 经三轮校订后的定稿：补内容、给收束段加上「本章小结」标题、删掉多数「它要解决什么问题」小标题），全书照抄，不另造体例：章首 `> **本章要解决的问题**` + 1./2./3. 疑问清单；`## N.M` 节 + `###` 三级标题；算例以 `**算例一：…**` 起头散在正文；旁注落副区；图下一行图题 + `**这张图要读出什么**`；章末「动手算一算（只留指引）→ 本章要点 → 本章术语表 → **本章小结**（承上启下的收束段，必须给它一个标题，不许裸挂在术语表后面）→（本章数值出处）→ 口径说明」。「例题编号」「公式编号」「每章参考文献小节」**不采用**（会改掉样子）。

**做这一件事之前，先读 `book-typography-cn`**（尤其它里面的 `references/textbook-layout-cn.md`）。本册只记「这本书怎么排」与「踩过的雷」，不重复通用版式理论。

## When to Use

- 要给这本书出新版（开本、版心、图、表、题解、文风一起动）。
- 要给别的中文教材套同一套版式与流程（参数改表即可）。

## 一、定版参数（PDF 实测，勿凭记忆改）

| 项目 | 值 |
|---|---|
| 开本 | **210×260 mm** |
| 页边距 | **天头 22 / 地脚 15 / 左右各 15**（页眉需占天头） |
| 版心 | **180×223 mm** |
| 版心内分 | **左副区 34 + 主栏 146** |
| 正文 | 五号 10.5 pt / 行距 17.2 pt → **39 字 × 36 行** |
| 页眉 | 基线距纸顶 **15**，细线 **17.6**；页码贴切口，中夹竖线，偶页章名、奇页节名；章首页不排 |
| 主色 | `#2f6f9f`（与插图同色）／色砖 `#1e4a6b` |
| 三线表 | 上下 **1.5 pt**、表头线 **0.75 pt**（Chromium 只认 0.75 的整数倍） |
| 图内线 | 坐标轴与曲线 **0.75 pt**、网格与主刻度 **0.4 pt**、不画次刻度（图缩到 65 mm 后，旧的 1.5 pt 会糊成黑边） |
| 图内字 | **8.5 pt**，全书一律；**图宽 ≤ 65 mm、高 ≤ 78 mm**（主栏 146 的 45%），见第六节 |

## 三、推进顺序（先文后图，勿颠倒）

全书改版分四段。**图必须在文案定稿后按新图清单重画**——图号一改，正文引用全废，先画图等于白画。

0. **先立规范**（3–5 路子代理并行，产物落 `BOOK/规范/`）：
   - 查国家教材规范（教育部《普通高等学校教材管理办法》、GB 3100/3101/3102 量与单位、GB/T 15834 标点、GB/T 15835 数字用法、GB/T 7714 文献著录、CY/T 200—2019 印刷、GB/T 22466 索引、图书编校差错率 ≤1/10000）；
   - 分两路诊断知识断层：每章「补什么 → 放哪节 → 为什么必需」，对照 Krane／Glasstone／IAEA／PDG 目录，不许凭空编；
   - 分两路逐句抓 AI 腔、意象、废话、口号标题，每条给行号、原句、改法。
1. **定骨架与规格**：合成 `BOOK/写作须知_v4.md`（样子＋公式六件事＋量与单位＋数字标点＋文风六禁＋自检）+ 每章规格表。骨架、文风、图规、附录的完整条款见 `references/spec-v3.md`；国标条款与可机器判项见 `references/national-standards.md`。
2. **正文改写**（每章一路，8–9 章一波）：照 ch05_v8 的样子改（章首导读、三级标题、算例、旁注、图与读图段、章末四段），补知识、去废话、改加粗与 term；另出一份**图清单 sidecar**（`规范/图清单_chNN.md`，格式样板见 `templates/figure-list.md`：图号、短题、画什么、宽 mm、高 mm、标注字数、由哪张旧图拆分或新画）。
   **每路简报必须自带国标三条**（禁 ppm → 10⁻⁶、核素左上标 ²³⁸U、范围用「～」）与三器自检命令——不写进简报，子代理不会主动做，事后还得逐章召回。题解路可以与下一波正文并行（8–9 路正文＋5 路题解，同时在跑 ≤15）。
   自检：`文风检查.py`＋`验收章.py`＋`规范检查.py`＋`term对齐.py`，四器全绿再收。
   实测节奏：9 路正文＋5 路题解并行（14<15）可行，单章 5–9 分钟；每批收齐先跑四器与数字差集，再放下一批——不要边收边发，否则同一条规矩要在十几路里各修一遍。
3. **题解改写**（每章一路）：题号与正文习题一一对应，数字逐字不变。
4. **重画插图**（每章一路）：照图清单写 `code/fig_chNN_v3.py`，`figcheck.py` 全绿；拆图后**先把全章图注与「图 N-K」引用同步改完**再装配。
5. **全书装配**（`版式对照_有机化学风/build_book.sh`）：封面 → 卷首 → 各章 → 书末《题解》升为一章 → 附录 A–E，一次出全本。要点：
   - 图用 `图v3/chNN/*.svg` 平铺到 `out/图`（符号链接），正文 `.png` 统一改 `.svg`；
   - 章末只留「动手算一算」指引，题干在装配时从**原稿** `src/chNN.md` 摘回（v8 稿里没有题干）；
   - 卷首开头的 `<div class="pagebreak"></div>` 要跳过，否则第 1 页是空白；
   - 封面与目录照《基础有机化学》的骨相做（细则与 CSS 见 `references/front-matter-and-toc.md`）：封面白底 + 顶部一条灰阶重复纹样 + 33 pt 特粗书名 + 英文副题 + 红色版次小标，**所有文字（含英文与版次）右对齐**（订口在左）；目录**每章一块**，章条 = 蓝底白字「第 N 章」方框**在副区里右对齐**（右沿贴 34 mm）＋ 章名**自主区左沿起**（同一行）＋ 一条拉到右端的下划线 ＋ 「/ 页码」，节为宋体、小节为仿宋（三层）；条目**只在主区**（146 mm 一分为二），**每章条目左右各半、读序先左后右**（`column-fill:balance`）；
   - **前置页的页序**：封面 → 空白（封二）→ 版权页 → 空白 → 目录 → 正文；版权页底部那段自印说明离底约 60 mm、居中、不用句号、一句一行；封面与版权页均不排页眉页码，目录页排「目录」；
   - **版权页与目录不能省**：成品页序是 封面 → 版权页 → 目录 → 正文。缺这两页，装订审阅必判 A 级。版权页写书名、卷次、版次、开本、性质；
   - **目录页码是第二遍的事**：首装时 `src/toc_entries.json` 不存在、目录退回简目；跑 `toc_pages.py` 回填 → 重装 → 章条与节条目页码才准；
   - **任何改分页的改动（加前置页、修正文、补图）都会让索引页码全错**：顺序固定为「先 `toc_pages.py` 定目录 → 再 `index_pages.py` 重算索引 → 最后装一遍复核」。颠倒会得到「目录对、索引错」。
   - `finish.py` 里**第一章之前的所有页都要跳过页眉页码**（封面、版权页、目录）。从书签取第一章页码 `first_chap`，写 `if p < first_chap: continue`；只写 `if p == 0` 的话，版权页与目录页会各自印上「2」「3」，装订审阅必判 A 级；
   - 调试时 `CHAPTERS="01" OUTNAME=单章试装 ./build_book.sh`，先验管线再跑全书；
   - **装配完先量字号直方图**（不是中位数）：正文页 10.48 pt 应占绝对多数，若 8.8 居多就是整本被缩，回雷区 A；
   - 索引页码两遍校准：全书 PDF 出来后跑 `index_pages.py` 写回页码 → 重装 → 再跑一次，两遍页码一致才算定稿（页码列会改索引篇幅，一遍不稳）。

6. **三路独立审阅**（全书装订之后，6 路并行）：
   - 内容读校按卷切三路（每路 5–6 章），只读 `src/*_v8.md`，只写 `规范/审读_v3_*.md`，**不许改正文**；每条给「文件:行号｜原文（截）｜问题｜改法」，按 A（会让读者学错或卡住）／B（降低效率）／C（不好看）分级，末附「最该先改的 10 条」。
   - 插图审阅两路（ch00–08 / ch09–17），**可以改 `code/fig_chNN_v3.py` 并重跑**，但改完必须 `figcheck` 全过、`fs.audit` 为 0，且不许改正文（图文冲突只写进报告，由正文修订路处理）。
   - 装订审阅一路：量 PDF——字号直方图、行距、版心、表题与图题位置、空白页、书眉归属。
   - 收报后按卷切三路修订代理，每条改动写「旧值→新值→依据」，A 级全改、B 级尽量、C 级择要；不要给修订代理「自由改写」的口子，否则一轮审阅的收益会被新引入的改动抵消。

每章收工前仍要：

- **抽六页审**：章首、正文带边注页、图页、表页、例题页、题解首页。用 `vision_analyze` 逐页问：压字？溢出？缩进？行距？
- **量**：`measure_pdf.py` 字号必须 10.4–10.6、行距 16.8–17.4；不对就是整页被缩放（见雷区 A）。
- 记入 `BOOK/版式对照_有机化学风/对照报告.md`。

## 四、文风 v3（教材体，不是科普聊天体）

1. **禁 AI 腔与正确废话**（「请记住」「简单来说」「换句话说」「值得注意的是」「一句话看懂」「三分钟搞懂」）。判据：删掉这句，读者少了什么？
2. **禁意象与比喻**（墙、面孔、账本、闯关、门、钥匙、旅程、「想出的办法很聪明」）。物理类比只在能替代公式时保留，且紧跟一句适用条件。
3. **禁口号式标题**（「一句话看懂」「三分钟搞懂」）。`### 它要解决什么问题` 是第 5 章样张的样子，保留，但**每章 ≤3 处**，其余换成实义名词短语（如「截面的定义与单位」）。
4. **人称**：用「我们」或无人称；「你」≤ **2 次/千字**，且只用于操作指令。
5. **加粗 ≤4 处/千字**，只标要背的结论、易错判据、定义名，不标语气。
6. **专有名词首现**：`<span class="term">截面</span>（<span class="en">cross section</span>）`；同词全章一次，不落标题／旁注／表／图注。
7. **数字与单位**：量符号斜体、单位正体，数值与单位间空 1/4 格（`$E=2.5\ \mathrm{MeV}$`）；范围用「～」不用「-」；百分数写「4%」；中文数词只用于「三步」「两类」。

自检：`验收章.py`（第九节），AI 腔 0、口号标题 0、加粗 ≤4、term ≥8、图注数＝唯一图引用数；`规范检查.py` 全绿（单位、ppm、核素上标、范围「～」、图必被引用）。

## 五、表格定宽算法（`shape.py: fit_tables()`）

1. 格内 `①②③` 先各自起行（不定断点，量宽无意义）；
2. 每列取「最长那条不折行」的宽，**首列必须一行，永不压缩**；
3. 余量均分到各列；
4. 主栏 146 放不下 → 开副区 180（`table.wide`）；
5. 仍放不下 → 在非首列的 `；`→`，`→`、` 处断行，**只断该列最长那一格**，断完重算；
6. 仍不够 → 首列不压、其余等比例收。

**量宽前必须剥掉 LaTeX**（`\mathrm`、花括号、`^_`），否则 `^{56}\mathrm{Fe}(n,n')^{56}\mathrm{Fe}^*` 被当三十多个字，列宽虚胖一倍，表格白白开副区。

已实测：表 5-1 27/21/37/61=146（主栏）；术语表 23/45/112=180（只此一张开副区）。

### 细文三条（用户逐条定过，机理与 CSS 见 `book-typography-cn` 的 `references/textbook-layout-cn.md`）

- 表内文字**一律左对齐、上下居中**（数值格也不右齐，只保 `tabular-nums`）。
- 「要点／小结」列表**不打圆点**，按段落排（首行缩进两字）。
- 三级标题编号与标题**同号同字重**（11pt），只以主色区分。

## 六、图：小图、单幅、字号固定

| 项目 | 值 |
|---|---|
| 最大宽度 | **65 mm**（主栏 146×45%）；常用 52／58／65 |
| 最大高度 | **78 mm**（含轴标） |
| 图内字 | **一律 8.5 pt**（轴标、刻度、图例、示意标注同号） |
| 线宽 | 轴与曲线 0.75 pt、网格 0.4 pt、不画次刻度 |
| 画布 | 按印刷毫米数出图，插入时**不缩放** |

- **数据图**（折线统计图为主）：只留坐标轴、轴标、刻度、≤4 字的短图例；**禁止**图内解释句、公式、阈值注记、色块内文字、`(a)(b)` 标号。曲线多于三条改线型，说明进图注。
- **示意图**（剖面、几何、流程）：标注保留，但每条 ≤5 字、全图 ≤24 字，不压线不压箭头。
- **双拼／三拼一律拆成单幅独立编号**：65 mm 下每格仅 32 mm，8.5 pt 字必然互压。拆图后图注、正文「图 N-K」引用、插图目录三处同步改。
- 主刻度 ≤5 个：8.5 pt 的「10⁻⁵」约占 8 mm，刻度一密就叠字。

## 八、雷区（都踩过，别重踩）

**A. 整本书被缩到 84%（正文 10.5 → 8.84 pt，行距 17 → 14.5）**：Chrome 打印按「适合可打印宽度」**整本等比缩放**——只要有一处元素宽过 180 mm，全书都缩，单看某一页很难发现。实测三种来源，逐条堵：

1. `main{padding-left:34mm}`（早期写法）→ 打印时被算成额外宽度。用 `main > *{margin-left:34mm}`，且该规则必须排在 `p{margin:0}` 之后（`*` 不计权重）。
2. **`body{width:210mm; padding:22mm 15mm}` 在打印里仍生效** → 内容总宽 240 mm。打印块里补 `html,body{width:auto;margin:0;padding:0}`，页边距只由 `@page` 给。
3. **pandoc 给部分表写行内 `style="width:100%"`** → 100% 按 180 mm 算，再叠 `main > *` 的 34 mm 左边距 = 214 mm。→ 打印块写 `table:not(.wide){width:146mm !important}`，并在 `shape.py` 定宽后加一道 `ensure_wide()`：colgroup 合计 ≥176 mm 就补 `class="wide"`（并把 `table.wide{width:180mm;margin-left:0}` 提到不分层级、带 `!important`）。

**诊断两招**（详见 `references/assembly-and-scale.md`）：`measure_pdf.py` 的「字号中位数」会被表格字（8.8 pt）拖偏，不能当判据——按页统计字号直方图，正文字号应占多数；定位撑宽元素用屏幕模拟打印 CSS + headless Chrome 跑 JS 量 `getBoundingClientRect().right`，**跳过 `closest("svg")`/`closest("math")`**，否则 KaTeX 的 400em 伸缩路径会淹没结果。

**B. 某一段单独蹿进副区**：给该类段落写了 `margin` 简写（`.qstem{margin:0 0 4pt}`），权重压过 `main > *`。→ 只写 `margin-bottom`。

**C. 表格塌成一字一列、正文压表**：改旁注的正则 `<blockquote>…(.*?)</p></blockquote>` 遇上块内有 `<ol>` 就一路吞掉后面几段。→ 逐块扫描（`shape.py: shape_quotes()`）。

**D. 列宽改不动**：pandoc 给每个 `<col>` 写行内 `width:33%`，样式表压不住。→ `!important`，或干脆删 colgroup 自己写 mm。

**E. 开了副区仍按 146 排**：只写了 `main > table.wide{margin-left:0}`，漏了 `table.wide{width:180mm}`。

**F. 线宽全是 0.75 pt**：CSS 写 1pt 与 0.5pt，Chromium 按 96 dpi 取整都落到 1px=0.75pt。→ 用 1.5／0.75。

**G. 行内公式被拆散**：给带公式的段落上 `display:flex`，行内子元素各自成 flex 项。→ 题干文字包进一个 `<span>`。

**H. 行首标点（70 余处）**：Chromium 不实现 `line-break:strict`；插 U+2060 反而更多（可在其前断行），包 nowrap 片段也无效（可在行内盒边界断行）。→ 如实列为已知缺陷，别假装解决。

**I. 宽图推页留白**：图放不下就整页下移，页尾空三成。排版后期人工挪图或改图幅，CSS 无解。

**J. 字号检查误杀 mathtext**：matplotlib 的数学标签按下标比例出 5.95 px（8.5×0.7），`figcheck.py` 若不放行 5.95 会把每张带公式的图都判不合格。判据：只把 `> 8.5` 与「明显不合比例的小字号」当错，5.95/5.1 属正常上下标。

**K. 拆图不换号**：把 (a)(b) 拆成两张后只加图不重编号，正文「图 5-3」仍指旧的双拼图，读者对不上。→ 拆图与正文改写必须在同一轮完成，图注、引用、插图目录三处一起核。

**L. 65 mm 下沿用旧标注**：直接把 146 mm 的图缩到 65 mm，轴标与曲线注记会互压、刻度数字叠成一团。→ 图必须**按 65 mm 重新布局**（减刻度、移注记、必要时删曲线），不是等比缩小。

**M. 给 `caption` 写 padding 会把整张表推右**：`caption{padding:0 14mm}` 在 Chromium 里连表一块儿右移 14 mm（实测表左沿 49 → 63 mm），因为 caption 的盒宽参与了表盒计算。→ 表题要居中，只用 `width:146mm; text-align:center; padding:0`（`table.wide` 用 180 mm）；别再试 `margin:auto`，表题盒不服从左右 auto。判据：PDF 里表题中心 = 表中心 = 122 mm（版心 15+34+146/2）。

**N. 表题与图注不同款**：图注 `.figno` 与表题 `.tabno` 必须同构（衬线 8.5 pt、居中、主色号），否则同一本书两套标题字体。→ `shape.py: shape_tab()` 把 `<caption>` 包成 `<span class="tabno">`；CSS `caption{width:146mm;text-align:center;padding:0}`（`table.wide caption{width:180mm}`）。判据：PDF 里表题 8.48 pt、中心 = 表中心。

**O. 某一条三级标题没编号、后面全部错位**：pandoc 给长标题的 id 会折行写成 `<h3\nid="…">`，而 `shape.py` 的正则只认 `<h3 id="`，该条就被跳过（症状：目录里出现一条裸标题，看着像上一级；编号从第二条起算）。→ 正则一律写成 `<h3[^>]*>.*?</h3>`，外层扫描与内层提取两处都要改；别用 `split('"')` 取 id 以外的假设。

**P. 目录双栏左边空了、右边堆满（或反之）**：`.toc-cols{column-fill:auto}` 会把短章的条目全堆在左列。照样书要“每章左右各半”就用 `column-fill:balance`；要“左列到底再右列”才用 auto。两者读序都是先左后右。

**Q. 页码要“目录算第 1 页”**：`finish.py`、`toc_pages.py`、`index_pages.py` 三处必须同口径：先找首张“目录”页（扁平文本以“目录”开头），页码 = 物理页 − toc_first + 1；`toc_pages`/`index_pages` 写回的就是这个印刷页码。好处：封面、空白页、版权页怎么增删都不影响目录与索引的数字。

**AB. 目录"只有长章分两栏"**：`.toc-cols{column-count:2;column-fill:auto}` 会把内容短的章全堆在左列，只有条目多的章（附录 C 那种）才溢出到右列——用户一眼就看出"为什么只有公式速查分成两半"。→ 栏填充用 `column-fill:balance`：每章条目左右各半，读序仍是左列读完再右列；判据：抽一章数左右列条目数（如 31/31），短章也要两边都有。

## 十一、把套件打包转交（含开源）

分享给别人时，交付物不是 `版式对照_有机化学风/` 原样，而是一份**自解释的包**：

```
01-技能-hep-textbook-rebuild/  02-技能-book-typography-cn/
03-工具/  04-模板/（template.html + build.sh）  05-样张/（md + 成品 PDF + 抽页 PNG）
06-参考/（bookstyle.py、对照报告）  README.md
```

八条硬规矩：

1. **README 由打包脚本复制进暂存目录**，别先手写再跑脚本——脚本开头的 `rm -rf "$STAGE"` 会把它一并删掉（症状：暂存目录看着对，zip 里却没有 README）。源文件放在工具目录里（如 `工具/套件README.md`）。
2. **绝对路径一律参数化**：`build.sh` 里写死的 PyMuPDF 解释器 sed 成 `${PYMUPDF:-python3}`；`BOOK/`、`SAMPLE/` 这些本机路径写进 README 的目录约定，不要带出包外。
3. **封包前对包内每个 `.py` 跑 `python3 -c "import ast;ast.parse(open(f,encoding='utf-8').read())"`**——实测过技能里一个脚本两句写在同一行、`SyntaxError` 根本跑不起来；语法错的工具比没有更坑人。解压后再跑一次，确认包内无误。
4. **样张只留十张以内的代表页**（章首、题干满宽、术语表、题解、宽图、窄图、页眉、要点……），不要历次迭代的 `校_*.png` 全塞进去；包会从 5 MB 涨到 20 MB，发不出去。
5. **样张的图要与正文、与《图表规格》同代**：正文 v8 引用 5 张图，若样张的图目录还是 v2 那套（只 4 张、146/180 mm），出图时少一张，图注整体错位一格（图 5-2 的注落到图 5-1 上），且与 65 mm 规格互相打脸。→ 样张照 `图v3/chNN/*.svg` 落盘（放进 `fig5_chNN/` 供 `build.sh` 直接用，免得 figs.py 重画），封包前跑 `figcheck.py <样张图目录>`，并数「图注数 = 正文唯一图引用数」。
6. **交付说明分两层**：顶层 `README.md` 面向陌生人（参数一张表、依赖、怎么 build、已知缺陷）；原包里的详说明改名 `套件说明.md` 一并留着，两者不重复。
7. **README 用开发者口吻，不用 AI 口吻**：开头一句说清工具干什么，接规格表、依赖、一段可粘贴的命令、“几处容易踩到的地方”（症状→病根→怎么改）。禁“一图看懂”“三件最有用的东西”“已知缺陷（不是没做）”这类标题。插 3–4 张示例图（`<img src="05-样张/…png" width="420">` 两两并排，并在下一行写图说）；最后加一节「看不懂文档的话」：整包下载丢给 AI，附一句“读 SKILL.md 与套件说明，照流程排我的 src/”。
8. **README 里的图要验两道**：`raw.githubusercontent.com/…/main/<路径>` 逐张 `curl -o /dev/null -w %{http_code}` 应回 200；再 `curl` 仓库主页，确认渲染后 HTML 里有绝对化的 `src="/<账>/<repo>/raw/main/…"`——相对路径写错时页面只显示破图标。**校园网/代理环境下 raw 域名可能整个不通（curl 回 000、/raw/ 回 302 不跟到 objects.githubusercontent.com）**，此时改走 `gh api repos/<账>/<repo>/contents/<urlencode 路径> --jq .sha` 与本地 `git hash-object <文件>` 对比 blob sha，一致即证明远端字节无误，不要据此判定图挂了。

开源到 GitHub：

- `gh repo create <账>/<repo> --public --source=. --remote=origin --push`；仓库里放**解压后的内容**（可直接翻阅），zip 作为 **Release 附件**，不同时提交 zip。
- 许可证要与 README 的说法一致：README 写「不必署名」就别选要求保留声明的 MIT（选 0BSD/Unlicense）；不一致时以许可证为准、README 改口。
- 推完必须复核三重：`gh repo view --json visibility,licenseInfo,repositoryTopics`、`gh api repos/…/git/trees/main?recursive=1 --jq '[.tree[]|select(.type=="blob")]|length'`、`gh release view --json assets`。别信 `gh repo create` 那一行输出。
