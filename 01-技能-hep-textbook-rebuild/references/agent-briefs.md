# 两路子代理简报模板（实测可用）

派两路并行，各给一份自包含的简报——子代理看不见本对话，所有路径、格式、硬约束都要写进去。

## A 路：正文改写

附上：章号、输入 m d 路径、输出路径、`写作须知.md`（尤其第十一条文风四条）、本册的版式规矩。要求：

1. 段落节奏：8 行以上的长段拆成 2–5 行；每节开头先给判断句，不先说背景。
2. 旁注：原「> **旁注（可以跳过）**」与适合外移的插话（史料、易错点、单位换算、与前后章勾连）改写成 `> **旁注**\u3000…`。
   **每条 ≤60 汉字**（副区 30mm 只能容 10 字一行，超了就折成一长条），每节 0–2 条，全章 6–10 条。
3. 图：图内长标注移到图注；图注 1–3 句、必含「图 N-x」；图本身不改。
4. 习题：「## 动手算一算」整节删除，原位置只留一句指引。
5. 文风四条（AI 腔、编号、加粗、term 首现）在此轮一并做完。
6. **不许改**：数字、公式、节结构、旁注格式、图引用、表格。
7. 自检：`文风检查.py` 四项；汉字数与原稿相差 < 60。

## B 路：题解改写

附上：原章路径（题目在「## 动手算一算」里）、输出路径、`src/tijie.md`（结构样例）。

硬要求：

1. HTML 结构照抄：`.work / .tag / .q / .given / .steps / .step / .eq / .lead / .say / .a`。
2. `.eq` 只放公式（KaTeX），定宽列、居中；公式太长就拆成两步；实测宽度不超过 90mm。
3. `.say` 是「这一步在做什么」，**6–14 字**，各行起点对齐。
4. 承接上一步的推导用 `.step ind`。
5. 每题 3–8 步；必须有 问题 / 已知 / 解 / 答 四段。
6. `题 N-M` 编号从 N-1 起（N 为章号）。
7. **物理数字、单位、有效位数与原解逐字一致**；只重组呈现，不重算。
8. 自检：KaTeX 每个行内式能解析、`.eq` 实测无溢出、数字令牌与原解差集为空。

## 收到之后，自己跑这几条

```bash
cd BOOK/版式对照_有机化学风
/usr/bin/python3 工具/文风检查.py ../src/chNN_vN.md      # 四项指标
/usr/bin/python3 - <<'PY'                              # 不变量比对
import re
A=open("../src/chNN.md",encoding="utf-8").read()
B=open("../src/chNN_vN.md",encoding="utf-8").read()
def inv(s): return dict(
  行间公式=len(re.findall(r"\$\$.*?\$\$",s,re.S)),
  旁注=len(re.findall(r"^> \*\*旁注\*\*",s,re.M)),
  图=len(re.findall(r"!\[图 ",s)), 表格行=len(re.findall(r"^\|",s,re.M)),
  二极=len(re.findall(r"^## ",s,re.M)), 三级=len(re.findall(r"^### ",s,re.M)))
a,b=inv(A),inv(B)
print({k:(a[k],b[k]) for k in a})
na,nb=set(re.findall(r"\d+\.?\d*",A)),set(re.findall(r"\d+\.?\d*",B))
print("只丢:",sorted(na-nb)[:10],"只增:",sorted(nb-na)[:10])
PY
```

数字集合应完全一致；有增有减就是子代理改了物理，退回重做。
