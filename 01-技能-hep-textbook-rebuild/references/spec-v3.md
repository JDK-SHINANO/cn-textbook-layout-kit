## 一、章节样子（逐项照 ch05_v8）

```
<span id="chN"></span>

# 第 N 章　标题

> **本章要解决的问题**
>
> 1. …（3–5 个疑问句，编号保留）

（开篇 2–4 段：承接前章、点明本章的两三个工具、预告走向）

## N.1 节标题

### 它要解决什么问题
（2–3 段，先给判断；此型标题全章 ≤3 次）

### 两种写法 / 四条守恒 / …
（正文；公式 $$…$$；算例以 **算例一：…** 起头）

> **旁注**　…（≤60 汉字，落左副区）

![图 N-K　短题](图/…)
（图后一段 **这张图要读出什么**，2–4 句）

## 动手算一算
本章 N 道习题连同逐步详解，见书末《题解》第 N 章。

## 本章要点
- 5–8 条短句

## 本章术语
| 术语 | 英文 | 一句话定义 |
: 表 N-K　第 N 章术语表

---
（收束段 2–3 段：把符号交给后几章）
（本章数值出处：一段斜体小字）
（口径说明：同一物理量多值时在此交代）
```

**不采用**：例题编号（例 N-1）、公式编号（式 N-3）、每章参考文献小节——会改掉样子。算例仍以 `**算例一：…**` 起头，散在正文里；章末不加文献节，数据出处沿用「（本章数值出处：…）」一段。

## 三、文风 v3

全书用教材体写，不写科普聊天腔。

1. 禁 AI 腔与正确废话（「请记住」「简单来说」「换句话说」「值得注意的是」「一句话看懂」「三分钟搞懂」）。判据：删掉这句，读者少了什么？
2. 禁意象与比喻（墙、面孔、账本、闯关、门、钥匙、旅程、「想出的办法很聪明」）；类比只在能替代公式时保留，并紧跟适用条件。
3. 禁口号式标题；`### 它要解决什么问题` 属样子，保留但每章 ≤3 处，其余换实义名词短语。
4. 人称「我们」或无人称；「你」≤2 次/千字，只用于操作指令。
5. 加粗 ≤4 处/千字，只标要背的结论、易错判据、定义名。
6. 术语首现 `<span class="term">中文</span>（<span class="en">english</span>）`，同词全章一次。
7. 数值用阿拉伯数字，量符号斜体、单位正体，数值与单位间空 1/4 格；范围用「～」；百分数写「4%」。
8. 段长 2–5 行（39 字/行），一段一事，节首第一句给判断。
9. 旁注 `> **旁注**　…` ≤60 汉字，只放史料、易错点、单位换算、前后章勾连。
10. 每节末尾不写总结句，总结只在「本章要点」出现一次。

自检：`工具/文风检查.py`（硬门槛 R1–R4/R9/R11/R14/R15）、`工具/验收章.py`。

## 四、补充知识的口径

「补充」只补断层，不拿来加长。每处补充必须能回答「不读这段，读者会在哪卡住」。四类，按优先级：前置知识缺口、工程实情（真实堆型/器件参数）、数量级与量纲直觉、学科史与命名来由（只进旁注）。

反例不算补充：「核能很重要」「中国正在大力发展核电」「由此可见物理学之美」。

## 五、图规（摘）

- 宽 ≤65 mm、高 ≤78 mm；图内字一律 8.5 pt；画布按印刷毫米出图，插入不缩放。
- 线宽：轴与曲线 0.75 pt、网格 0.4 pt，不画次刻度；主刻度 ≤5 个。
- 数据图：只留轴、轴标、刻度、≤4 字短图例；禁解释句、公式、阈值注记、色块内文字、`(a)(b)`。
- 示意图：标注每条 ≤5 字、全图 ≤24 字，不压线不压箭头。
- 双拼／三拼拆成单幅独立编号；图注、引用、插图目录三处同步。
- 信息密集的图（衰变系、标准模型零件表、堆芯栅格）重画为极简版或改表格，不许旧图硬缩。
- 验收：`工具/figcheck.py`。

## 八、工程实现（可直接复用）

### 8.1 插图模块 `code/figstyle_v3.py`

```python
import figstyle_v3 as fs
fig, ax = fs.new(58, 44)          # 毫米；超 65×78 直接抛错；内部 layout="constrained"
ax.plot(x, y, color=fs.MAIN, lw=fs.LW_LINE)
fs.ticks(ax, 4)                   # 主刻度 ≤5，不画次刻度
ax.set_xlabel("能量 / eV")
bad = fs.save(fig, "ch05_fig2", outdir=f"图v3/ch05")   # 返回「互压对数+越界数」，必须为 0
```

- 字体名：本机 matplotlib 可用 `Noto Sans SC`；写 `Noto Sans CJK SC` 会静默回退成豆腐块。换机先查 `fontManager.ttflist`。
- `audit()` 只审可视文本（轴标/标题/注释/图例/范围内的刻度）。范围外刻度 matplotlib 也建 Text 对象但不画，拿 `findobj(Text)` 全审是假阳性。
- `figcheck.py` 对 mathtext 下标（5.95 pt = 8.5×0.7）放行，只把 `>8.5` 与不合比例的小字号当错。

### 8.2 附录自动生成（`工具/make_appendix.py`）

- 从各章 `## 本章术语` 表取（术语｜英文），按术语合并章号，**按汉语拼音排序**输出附录 D；从 `![图 N-K　题]` 取图题输出附录 E。
- 拼音序不装 `pypinyin`：本机 glibc 的 `zh_CN.UTF-8` collation 就是拼音序。Python 里把待排项写成 `术语\t英文\t章`，再：

```python
subprocess.run(["sort", "-s", "-k1,1", path], env=dict(os.environ, LC_ALL="zh_CN.UTF-8"))
```

- 索引表现在只有「章」列；GB/T 22466 要求「标目 + 页码」，**定稿前必须在终版 PDF 上重算成页码**（现稿未做，属必办项）。

### 8.3 全书装配（`build_book.sh`）
