# 国家教材规范：可执行清单

写中文大学教材时用来对条款。分两层：**可机器判**（脚本能扫）与**只能人判**（读稿时逐条核）。标准号与现行版本已核过，勿凭记忆改年号。

## 一、标准与边界

| 标准/文件 | 关键点 |
|---|---|
| 教育部《普通高等学校教材管理办法》（教材〔2019〕3 号） | 教材编写、审核、科学性与意识形态把关 |
| GB 3100-1993 / GB 3101-1993 / GB 3102 系列 | 量和单位；核物理量取 3102.9（半衰期 *T*₁/₂ 项号 9-39） |
| GB/T 15834—2011 | 标点符号用法 |
| GB/T 15835—2011 | 出版物上数字用法 |
| GB/T 7714—2025 | 文献著录。**2025 版已实施**：EB 改指网站网页，新增 [PP/OL] 预印本、[DS/OL] 数据集；引用旧 2015 版格式即为过期依据 |
| CY/T 200—2019 | 正式名《书刊印刷通用设计规范》（不是「图书出版流程管理规范」） |
| GB/T 22466—2023 | 索引编制规则（2009 为旧版） |
| 《图书质量管理规定》 | 编校差错率 ≤ 1/10000 |
| GB/T 788—1999 | 开本系列只有 A/B 系列；**210×260 不在其中**，属出版社自定特殊开本 |
| GB/T 18358—2009 | 只管中小学教科书，大学教材不适用 |

## 二、可机器判（规范检查.py 已实现）

| 项 | 判据 |
|---|---|
| 数值与单位贴死 | `\d(MeV|keV|eV|Bq|Gy|Sv|kg|mg|cm|mm|km|Pa|kW|MW|GW)` |
| ppm/ppb/pphm | 禁用（GB 3101 2.3.3 注 2），改 10⁻⁶、mg/kg、μL/L |
| 数值范围 | 短横线两侧是数且后跟单位/量词即错，应为「～」；图表编号的短横线不算。判据必须带「后跟单位/量词」这一条，否则 `$20.872-6.673$` 这类减法会被当成范围误报 |
| 核素写法 | `U-238`、`238U` 错，应 `$^{238}\mathrm{U}$`（质量数左上标）或「铀-238」 |
| 半衰期 | 只许 `$T_{1/2}$`；`t1/2`、`T1/2`、`T(1/2)`、`τ_{1/2}` 错 |
| ℃ | `25 ℃` 对，`25°C` 错；角度 `25°` 不留空 |
| 千分位 | 科技书用千分空 `12 500`，不用 `12,500` |
| 前导零 | `0.46`，不写 `.46` |
| 感叹号 | 正文 0 处 |
| 导语式标题 | `### 它要解决什么问题` 这类，每章 ≤3 |
| 图必被引用 | 图号集合 ⊆ 正文「图 N-K」引用集合；缺引用按「图表位置错」计入差错率，量大单项即不合格 |

## 三、只能人判（十项）

1. 量符号斜体、单位正体；函数名（sin、ln、exp）、微分号 d、自然对数底 e 正体且全书一致。
2. 数值与单位间 1/4 空（LaTeX `\ `）；词头正体、不叠用。
3. 核素首现「²³⁸U（铀-238）」，其后用符号；同段不混用三种写法。
4. 非 SI 单位（b、Ci、rad、rem、R）首现给换算，并注明「本书按 SI 表述，靶恩仅在与文献对照时使用」。
5. 表内单位提到表头（「能量/MeV」），同列不逐格重复；同列小数位一致；首列不折行。
6. 图题一句话 ≤35 字；数据图内不留解释句；示意图标注保留。
7. 表题用真 `caption`（表上），图题用 `figcaption`（图下）。
8. 「本章数值出处」写成三段式：用了什么量 + 哪一版评价（版本/年份）+ 哪张表或哪条记录。
9. 索引按**汉语拼音**排序（GB/T 22466 9.2.1.1），条目 = 标目 + 页码，图表出处加 T／I；英文序另立表，不得替代中文序。
10. 交叉引用不指向未写成的章（未写的卷四须删链接或标「待出」）。

## 四、版式硬指标（CY/T 200）

边空 ≥7 mm；页码不落订口、字边距切口 ≥3 mm；正文与表内字号 ≥5.5 P；线条 ≥0.1 mm、反白线 ≥0.2 mm；**细小文字不用反白**（6 pt 反白「CHAPTER」这类不合格，改 ≥8 pt 或改深色字）；黑字用单色黑；出血 ≥3 mm。

## 五、编校差错率自查口径

逐项乘权重累加，总分 ÷ 版面字数 ≤ 0.0001：知识性/逻辑性/语法性 2；正斜体与大小写 0.5（同一错超 3 处计 1.5）；计量单位与术语 1；科学符号 0.5；图表序 0.1（超 3 处计 1）；图表与说明不符 2；行首行末标点 0.1。

**优先清三类高权重低难度项**：图缺引用、行首标点、图表与说明不符——它们不是「排版瑕疵」，是直接吃掉公差。

## 六、与本书体例的取舍

- 图宽按用户要求 **65 mm**，优先于通用建议的「默认 146 mm」。
- 不设公式编号的前提：正文与题解里没有「式 (N-M)」引用（改稿前先 `grep "式 *[（(][0-9]"` 确认）。
- 核素：符号用 ²³⁸U，中文叙述用「铀-238」，禁 `U-238`；不做全书统一改成符号（叙述可读性优先）。
